# Browser Text Editor

A lightweight, offline-capable text editor that runs entirely in the browser. No backend, no account, no dependencies — just open it and write.
## Features

- **Works offline** — after the first load, the editor keeps working without an internet connection
- **Zero setup** — no install, no sign-up, no server
- **Instant load** — plain HTML, CSS, and JavaScript; no framework, no build step
- **Local-first** — your text stays in your browser, nothing is uploaded anywhere
- ## Tech Stack

- **HTML / CSS / JavaScript** — no frameworks, no build tools
- **Service Worker** — caches the app shell for offline use
- **localStorage** — persists drafts between sessions
